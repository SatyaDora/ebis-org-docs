# Organization: External Organizations

The External Organizations module manages third-party vendors, partners, subsidiaries, clients, and associated business entities[cite: 12].

* Navigate to **Organization > External Organizations** to open the searchable listing grid (displaying Organization Name, ID, Top Parent Status, Locations, Website, and Activation State)[cite: 12].

## Common Toolbar Actions
Toolbar options (**Clone**, **Delete**, **View**, and **Refresh**) follow standard application behavior[cite: 12].

![](media/slide077_img1.png){width=99%}

## Create / Edit External Organization

* Click create or select an existing organization to edit[cite: 12].
* **Basic Settings:** Enter Organization Name, Activation State, Parent Organization, Top Parent status, Website, Resolver Group, Phone numbers, Service Catalogue ID, and classifications (Market Tier, Organization Tier, Primary/Secondary Verticals)[cite: 12].
  
  ![](media/slide078_img1.png){width=93%}

  ![](media/slide078_img2.png){width=94%}

  ![](media/slide079_img1.png){width=94%}

* **Additional Details Tab:** Specify Region, Employee count, District, Sub District, and Locations[cite: 12].
  
  ![](media/slide080_img1.png){width=94%}

* **Other Details Tab:** Configure Base Technology Platform, Annual IT Budget, Market Cap, International Company flag, Security Clearance requirements, Trade Codes, stock exchanges, outsourcing affinity, images, and notes[cite: 12].
  
  ![](media/slide081_img1.png){width=94%}

  ![](media/slide082_img1.png){width=95%}
